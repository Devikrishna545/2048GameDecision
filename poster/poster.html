Takeaway

Start with a hosted model, log its decisions, then fine-tune an open model on them: 10× faster, $0 per call. The student only gets as good as its teacher.

Setup: seeded 2048 engine, identical boards for every player. Laya was LoRA fine-tuned to imitate ~8,100 moves by Jev and the corner rule, then tested on boards it never trained on. Jev did not play Round 2, so this is not a direct Jev vs fine-tuned Laya result. Jev API cost: $1.52; Laya runs free.
